# Quiz 1 - Self Profile & Hometown Website

A responsive, multi-page personal website showcasing my profile, background, and a visual guide to my hometown of **Gianyar, Bali**, including its culinary traditions and top tourist destinations.

Live Site: [https://daemon19.github.io/quiz1/](https://daemon19.github.io/quiz1/)

---

## 🌟 Overview

This website serves as a personal digital identity and cultural showcase. Built with clean HTML5, modern CSS3, and Bootstrap 5, it offers an inviting user experience with rich typography, warm aesthetics, and fully responsive layouts across mobile, tablet, and desktop devices.

---

## 📄 Website Pages

The website consists of 5 main pages:

1. **[Home (`index.html`)](index.html)** — The main landing page welcoming visitors with a hero section, personal tagline, and philosophy quote.
2. **[Profile (`profile.html`)](profile.html)** — Personal background, quick details, areas of interest (Frontend Development, Cultural Storytelling, UI/UX Design), and student profile.
3. **[Hometown (`hometown.html`)](hometown.html)** — Dedicated page about Gianyar, Bali — exploring its arts, traditions, and local atmosphere.
4. **[Local Food (`food.html`)](food.html)** — Highlights authentic Balinese culinary specialties such as *Nasi Campur Bali*, *Sate Lilit*, and *Bebek Betutu*.
5. **[Tourist Places (`tourist.html`)](tourist.html)** — Features iconic travel destinations in Gianyar including the *Sacred Monkey Forest*, *Tegallalang Rice Terraces*, *Tirta Empul Water Temple*, and visitor etiquette guidelines.

## 🎨 Design System & Color Palette

The visual style is inspired by the natural landscapes and rich heritage of Bali:

| CSS Variable | Color Hex | Visual Purpose |
| :--- | :--- | :--- |
| `--paper` | `#F6F3ED` | Warm cream/linen background providing an organic, comfortable reading surface |
| `--ink` | `#17211f` | Deep slate green-black used for hero sections, text headers, navbar, and footers |
| `--red` | `#DC3545` | Vibrant crimson accent for buttons, active navigation indicators, and numbers |
| `--sage` | `#C9D5C2` | Soft sage green for quote blocks, evoking Balinese rice fields and nature |

### Typography
- **Headings**: `Playfair Display` (Serif) — Elegant, classical display typography.
- **Body**: `DM Sans` (Sans-Serif) — Modern, legible geometric sans-serif font.
